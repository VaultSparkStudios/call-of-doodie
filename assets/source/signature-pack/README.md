# Signature Pack

Source-authored SVGs for Call of Doodie's first proprietary visual asset pack.

Regenerate runtime PNGs with:

```bash
npm run assets:generate
```

These are intentionally 3D-authored in style but 2D-delivered for runtime safety. The first pack focuses on the game's most readable identity beats: porcelain objective, plunger weapon, player operative, and Karen nemesis.
