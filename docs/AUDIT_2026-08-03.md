## Audit verdict

Call-Of-Doodie has unusually deep mechanics and strong automated guardrails, but it is presently **feature-rich and decision-poor**: the front door and post-run experience expose too many parallel explanations and actions, while the evidence plane needed to tune them has regressed. The optimal move is not another content pack. It is to restore trustworthy evidence, establish a fast runtime boundary, collapse intelligence into one verdict/action spine, collect privacy-safe human evidence, and then add compounding systems on top.

Release posture remains **FORGE / NO-GO for launch promotion**. Repo-owned improvements and isolated staging work should continue.

## Highest-value innovations

- **Insight Graph:** a typed, local, zero-token evidence graph that detects duplication and contradiction before producing one explainable recommendation.
- **Scenario Cartridges:** a bounded grammar for human- and agent-authored challenges using existing seed, loadout, mutation, objective, and proof primitives.

- **Playtest Pulse:** a visible, consented feedback flywheel built from the existing local flight recorder, with redacted export before any network upload.
